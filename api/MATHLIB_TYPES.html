    Common typedefs¶

    group Common typedefs

    This module consists of common typefeds to all MATHLIB kernels.

    Typedefs¶

    typedef MATHLIB_STATUS_NAME MATHLIB_STATUS¶

    Return value for MATHLIB functions.

    Enums¶

    enum MATHLIB_STATUS_NAME¶

    The enumeration of all status codes.

    Values:

    enumerator MATHLIB_SUCCESS¶

    0 => No error

    enumerator MATHLIB_ERR_FAILURE¶

    1 => Unspecified error

    enumerator MATHLIB_ERR_INVALID_VALUE¶

    2 => Invalid parameter value

    enumerator MATHLIB_ERR_INVALID_TYPE¶

    3 => Invalid parameter type (MATHLIB_data_type_e data_type)

    enumerator MATHLIB_ERR_INVALID_DIMENSION¶

    4 => Dimension parameter (width/height) is too big/small

    enumerator MATHLIB_ERR_NULL_POINTER¶

    5 => Unsupported null pointer condition

    enumerator MATHLIB_ERR_NOT_IMPLEMENTED¶

    6 => Parameter configuration is not supported/implemented

    enumerator MATHLIB_ERR_NOT_EQUAL_WIDTH_STRIDE¶

    7 => Stride should be equal to width * element size

    enumerator MATHLIB_ERR_NOT_ALIGNED_PTRS_STRIDES¶

    8 => Pointers and stride values are not aligned to documented value

    enumerator MATHLIB_ERR_NOT_ALIGNED_WIDTHS¶

    9 => Width values are not aligned to documented value

    enumerator MATHLIB_ERR_BUFFER_TOO_SMALL¶

    10 => Buffer size not large enough

    enumerator MATHLIB_ERR_INVALID_ACTIVATION¶

    11 => Activation selection incompatible with data type

    enumerator MATHLIB_ERR_INVALID_SHIFT¶

    12 => Requested shift amount is not valid

    enumerator MATHLIB_ERROR_MAX¶
